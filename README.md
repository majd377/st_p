# بوابة الطلاب — النسخة المعاد بناؤها

- `index.html`: موقع الزوار للعرض فقط.
- `admin/index.html`: لوحة الإدارة المنفصلة.
- `assets/css/style.css`: كل التنسيق في ملف مستقل.
- `assets/js/app.js`: منطق التطبيق والصفحات.
- `assets/js/firebase-config.js`: إعداد Firebase العام (هذه المفاتيح ليست سرية بحد ذاتها؛ الحماية الحقيقية في Rules).
- `assets/js/admin.js`: دخول Google والتحقق من الحساب المصرح به.

## الجدول الأسبوعي
من لوحة الإدارة افتح «الجدول الأسبوعي». يمكن تشغيل/إيقاف استخدام الجدول. عند عدم وجود روابط مباشرة لليوم، تُستخدم روابط اليوم من القالب الأسبوعي تلقائياً.

## GitHub Pages
ارفع محتويات المجلد إلى المستودع مع الحفاظ على مجلد `assets` و`admin`. لا تحذف `.nojekyll` إن أضفته.

## Firebase
طبّق `database.rules.json` على Realtime Database، وفعّل Google Sign-In، وأضف دومين GitHub Pages إلى Authorized Domains.

## ملاحظة الأمان
لا يمكن إخفاء JavaScript عن مستخدم المتصفح بنسبة 100% لأن المتصفح يحتاجه لتشغيل الموقع. تم فصل الملفات وتصغيرها/تشويشها في نسخة الإنتاج عند الحاجة، لكن منع التعديل يعتمد على Firebase Rules وليس على إخفاء الكود.
