# المنارة الطلابية — V8
- CSP: إضافة *.firebaseio.com لـ script-src (Firebase يستعمل Long-Polling عبر وسم script عند تعذر WebSocket، وكان هذا سبب الخطأ المتكرر)، وcdnjs لمكتبة 3D.
- boot.js: عند أول فتح للنسخة الجديدة يحذف الكاش وخدمة العمل القديمة ويعيد التحميل مرة واحدة، دون لمس localStorage أو بيانات Firebase.
- توافق: JS مُحوَّل لدعم المتصفحات القديمة (ES2017: Chrome 58 / Safari 11 / Firefox 53)، وCSS بدائل لـ inset، والـ 3D يتعطل بهدوء إن لم يدعم المتصفح PointerEvent.
- تصميم: منارة ثلاثية الأبعاد (Three.js r128 من cdnjs) بكتب أقسام تدور حولها، شعاع ضوء، موجات وغبار؛ اسحب للتدوير واضغط على كتاب لفتح القسم. مع انتقال ثلاثي بين الأقسام وضوء يتبع المؤشر وزجاج للشريط الجانبي.
- manifest: id/scope وأيقونة maskable منفصلة.
